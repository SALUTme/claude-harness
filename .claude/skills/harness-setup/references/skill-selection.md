# Фаза 3. Подбор скиллов и агентов

## 1. Инвентарь

```bash
ls ~/.claude/skills 2>/dev/null
ls .claude/skills .claude/agents 2>/dev/null
jq -r '.enabledPlugins // {} | keys[]' ~/.claude/settings.json 2>/dev/null
```

Добавь агентов, которые видны в текущей сессии. Если стоит oh-my-claudecode, у него уже есть planner, architect, executor, code-reviewer, verifier, test-engineer, security-reviewer, designer и debugger.

## 2. Потребности

Из PRD и BRIEF выпиши возможности, которые понадобятся: стек, тестирование, интерфейс, база данных, деплой, безопасность, предметная область. Для каждой отметь, чем она уже закрыта.

## 3. Поиск для пробелов

По порядку:
1. Инструменты `SearchSkills` и `SearchPlugins`, если они есть в сессии.
2. Каталог skills.sh. Команда `npx skills` скачивает пакет из npm, поэтому первый запуск только с согласия пользователя:
   ```bash
   npx --yes skills find "<запрос>"
   ```
3. Официальные источники: anthropics/skills, vercel-labs/agent-skills.

## 4. Проверка кандидата

Не рекомендуй скилл только по результатам поиска. Для каждого кандидата:

| Критерий | Норма |
|---|---|
| Установки | Лучше от 1000. Меньше 100 требует особой осторожности |
| Звёзды репозитория | Меньше 100 требует особой осторожности |
| Лицензия | Указана |
| Обновление | Не старше полугода |
| Автор | Известная организация или проверяемая репутация |

Затем посмотри содержимое без установки:
```bash
npx --yes skills add <owner/repo> --list
curl -sL https://raw.githubusercontent.com/<owner>/<repo>/<ветка>/<путь>/SKILL.md
```

Прочитай SKILL.md целиком. Красные флаги:
- хуки во frontmatter;
- скрипты с сетевыми вызовами, особенно `curl | sh`;
- широкие `allowed-tools`, например голый `Bash`;
- инструкции отключать проверки, игнорировать правила или пересылать данные;
- очень длинное описание, которое будет съедать контекст в каждой сессии.

## 5. Таблица для пользователя

| Потребность | Кандидат | Источник | Установки или звёзды | Лицензия | Обновлён | Что делает | Риски | Совет |
|---|---|---|---|---|---|---|---|---|

Правило экономии: на старте не больше пяти новых скиллов. Лучше ничего, чем посредственный скилл.

## 6. Установка одобренного

По умолчанию на уровне проекта, чтобы скилл жил вместе с репозиторием:
```bash
npx --yes skills add <owner/repo> --skill <имя> -a claude-code -y
```
Флаг `-g` не используй: глобальные скиллы ставятся в `~/.claude`, а облачные сессии их не видят. Скилл, нужный во всех проектах, добавляется в основу harness.

После установки проверь, что папка появилась, и прочитай установленный SKILL.md.

## 7. Агенты

1. Сначала используй существующих агентов.
2. Своего агента в `.claude/agents/<имя>.md` создавай только для предметной роли, которой нет, например ревьюер по отраслевым требованиям.
3. Минимальный формат:
   ```markdown
   ---
   name: <имя>
   description: <когда вызывать>
   tools: Read, Grep, Glob, Bash
   model: opus
   ---
   <роль, что проверять, формат вердикта>
   ```
